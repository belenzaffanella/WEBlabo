# Laboratorio Golinelli — MVP

Sitio estático responsive preparado para GitHub Pages.

## Archivos del sitio

- `index.html`: contenido y estructura.
- `styles.css`: diseño adaptable a escritorio, tablet y celular.
- `script.js`: menú y formulario de contacto por WhatsApp.
- `indicaciones.js`: buscador y fichas de preparación.

El workflow de GitHub Pages publica solamente estos cuatro archivos. La documentación de trabajo para los dueños queda fuera del sitio publicado.
